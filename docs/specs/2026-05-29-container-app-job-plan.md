# container-app-job Module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a new `modules/container-app-job` module wrapping `azurerm_container_app_job` with support for all three trigger types, managed identity + KV secret auth, and private registry pulls.

**Architecture:** New module directory scaffolded from scratch following existing module conventions. Core resource is a dual-instance pattern (`with_lifecycle` / `without_lifecycle`) gated by `count` to work around Terraform's static `lifecycle` limitation. All outputs routed through `local.job` abstraction. Trigger constraint enforced via a `check` block.

**Tech Stack:** Terraform >= 1.10.0, AzureRM provider >= 4.0.0

  )
