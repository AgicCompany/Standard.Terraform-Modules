# container-app registry support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `registries` variable and `dynamic "registry"` block to `modules/container-app` to enable private ACR pulls via managed identity or username/password auth.

**Architecture:** Single new optional variable (`registries`, default `[]`) with two inline validation blocks. One `dynamic "registry"` block added to the existing `azurerm_container_app` resource. No new resources, locals, or outputs. Complete example updated to demonstrate managed identity registry auth via a data source lookup.

**Tech Stack:** Terraform >= 1.10.0, AzureRM provider >= 4.0.0

### Task 1: Add `registries` variable to `variables.tf`

**Files:**
- Modify: `modules/container-app/variables.tf`

- [ ] **Step 1: Add the variable**

Open `modules/container-app/variables.tf`. Locate the `# === Optional: Configuration ===` section. Add the following block after the `init_containers` variable and before `# === Optional: Feature Flags ===`:

```hcl
variable "registries" {
  type = list(object({
    server               = string
    identity             = optional(string)
    username             = optional(string)
    password_secret_name = optional(string)
  }))
  default     = []
  description = "Private registry authentication. Each entry requires either 'identity' (resource ID of a user-assigned managed identity) or both 'username' and 'password_secret_name'. The identity must be present in user_assigned_identity_ids."

  validation {
    condition = alltrue([
      for r in var.registries :
      (r.identity != null) != (r.username != null && r.password_secret_name != null)
    ])
    error_message = "Each registry entry must use either 'identity' or both 'username' and 'password_secret_name', not both methods and not neither."
  }

  validation {
    condition = alltrue([
      for r in var.registries :
      (r.username == null) == (r.password_secret_name == null)
    ])
    error_message = "'username' and 'password_secret_name' must be set together."
  }
}
```

- [ ] **Step 2: Format and validate**

```bash
make fmt MODULE=container-app
make validate MODULE=container-app
```

Expected: `=== container-app OK ===` with no errors.

- [ ] **Step 3: Commit**

```bash

git commit -m "feat(container-app): add registries variable for private registry auth"
```

### Task 2: Add `dynamic "registry"` block to `main.tf`

**Files:**
- Modify: `modules/container-app/main.tf`

- [ ] **Step 1: Add the dynamic block**

Open `modules/container-app/main.tf`. Locate the `# Identity` dynamic block. Add the following block immediately after it (before `tags`):

```hcl
  # Registry
  dynamic "registry" {
    for_each = var.registries

    content {
      server               = registry.value.server
      identity             = registry.value.identity
      username             = registry.value.username
      password_secret_name = registry.value.password_secret_name
    }
  }
```

- [ ] **Step 2: Format and validate**

make fmt MODULE=container-app
